# Simple E-Commerce Cart

This is a simple shopping cart application built using **HTML, CSS, and JavaScript**. Users can add products to the cart, view the total price, and complete the checkout process.

## Features

* Display a list of products
* Add products to the shopping cart
* Calculate the total price
* Checkout and clear the cart

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
